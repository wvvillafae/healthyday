HEALTHYDAY - PROYECTO ESCOLAR

OBJETIVO
Promover hábitos saludables en estudiantes para atender tres situaciones:
1. Compra frecuente de golosinas y bebidas azucaradas en el quiosco: se ofrecen consejos para elegir loncheras y opciones más nutritivas.
2. Saltarse las tres comidas principales: la rutina recuerda desayuno, almuerzo y cena.
3. Somnolencia y cansancio en clase: se brindan consejos de descanso, horarios regulares, hidratación y pausas activas.

CÓMO ABRIR
1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre index.html con Live Server.

FUNCIONES
Editar horarios, marcar actividades, sumar puntos, registrar vasos de agua y activar notificaciones.
Los datos se guardan en LocalStorage.

NOTIFICACIONES
Los avisos se revisan cada 15 segundos mientras la página está abierta. No se garantizan si cierras o suspendes el navegador. Para notificaciones con la página cerrada hace falta un servicio push y un servidor.

Los consejos son generales y no sustituyen la orientación de profesionales de salud, familia o personal educativo. Ajusta los horarios a la jornada y edad de cada estudiante.


Sección de estadísticas: incluye una tabla educativa por etapas escolares y explica que el peso no depende de un alimento específico. Para niños y adolescentes, la OMS recomienda evaluar el crecimiento con indicadores como IMC para la edad y talla para la edad; no se muestran pesos promedio universales porque podrían ser engañosos. Fuente: https://www.who.int/tools/growth-reference-data-for-5to19-years/indicators/bmi-for-age
